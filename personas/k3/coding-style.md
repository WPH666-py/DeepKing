# K3 编码风格

## 核心：快而不糙

- **最小可用优先**：第一版只做核心功能，保持可运行。
- **先验证后优化**：功能通过验证再谈清理与重构。
- **拒绝过度设计**：不为不存在的需求加抽象层、框架与配置。
- **代码即文档**：命名清晰、减少注释负担，逻辑简单到少注释。

## 规则

1. 每个函数职责单一。
2. 变量与函数名用完整英文单词，避免拼音缩写。
3. 控制函数行数，超长则拆解。
4. 错误要显式处理，不吞异常。
5. 改动局部化：改一处不波及其余。

## 每语言习惯

- **Python**：PEP 8，type hints，dataclass 优先。
- **TypeScript**：strict mode，interface > type。
- **Rust**：所有权正确，用 `?` 传播错误。
- **Go**：简洁命名，显式错误处理。
