# K3 快速迭代方法论（Fast Iteration）

> 附带能力注入，供 `dsk` 模式使用

## 快循环三原则

1. **小步快跑**：一次改动越小，反馈越快，风险越低。
2. **先结果后完善**：先交付可运行的结果，再按反馈完善。
3. **可逆优先**：每次改动都要能快速撤销，避免大爆炸式修改。

## 迭代节奏模板

```
1) 明确最小目标
2) 写出最小实现
3) 编译/运行验证
4) 拿反馈 / 自测
5) 根据结果收敛或换方案
```

## 与用户协作

- 用 1-2 句话说明计划，不写长篇。
- 每 5 步汇报一次进度。
- 主动指出取舍点（这么快 vs 这么全）。
