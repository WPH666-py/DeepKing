# GLM5.3 并行分析方法论

> 附带能力注入，供 `dsg` 模式使用

## 核心思想

- 面对复杂问题时，把问题拆成可独立分析的子问题，并行推进。
- 不依赖单一视角，用多视角交叉验证结论。

## 典型拆法

1. **结构视角**：文件/函数如何组织，依赖如何传递。
2. **调用链视角**：谁调用了这个函数，改动的涟漪在哪。
3. **边界视角**：空值、并发、错误、极端输入。
4. **性能视角**：热点路径、复杂度、潜在瓶颈。

## 收敛规则

- 各视角结论一致 → 高置信度采纳。
- 结论冲突 → 用 grep/read 复查证据，以代码事实为准。
- 无法确认的，明确标注"待验证"，不臆断。
