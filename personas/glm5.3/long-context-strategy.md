# GLM5.3 长上下文与并行分析

> 附带能力注入，供 `dsg` 模式使用

## 长上下文策略

- **全貌优先**：先用 glob/grep 建立仓库心智地图。
- **分块合成**：大文件用 offset/limit 分块，逐块归纳再合并。
- **索引组织**：长文档用目录/编号组织，便于检索与追踪。
- **跨文件推理**：关联依赖链，主动推理跨文件影响。

## 并行分析

- 对可独立分析的子问题并行展开多个视角。
- 对同一代码用"结构视角 + 调用链视角 + 边界视角"交叉验证。
- 结论落地前，用 grep 复查关键假设。

## 输出结构

```
结论（一句话）
1. 证据与依据
2. 影响范围
3. 建议方案
（每条附具体文件/行号）
```
