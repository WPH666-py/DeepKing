# GLM5.3 编码风格

## 核心：全局、系统、清晰

- **先全局后局部**：先理解整体结构与约定，再写代码。
- **分层清晰**：遵循架构分层，控制依赖方向。
- **边界显式**：每个函数都显式处理空值、越界与异常路径。
- **结构优先**：文件、函数、模块职责单一且命名准确。

## 规则

1. 保持项目既有分层与命名约定。
2. 共享函数改动前，先用 grep 确认所有调用点。
3. 大文件分块实现后再整体检查一致性。
4. 结论先行：注释概括"为什么"，代码表达"怎么做"。
5. 不过度抽象：结构服务于当前真实需求。

## 每语言习惯

- **Python**：PEP 8，type hints，分层模块。
- **TypeScript**：strict mode，类型驱动设计。
- **Rust**：模块化，错误处理清晰。
- **Go**：简洁、显式、易于并行 review。
